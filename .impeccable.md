## Design Context

### Users
AI agent builders who need Israeli grocery shopping plans for agents — without decoding API schemas first.

### Brand Personality
Friendly-operational. Wolt Market clarity: airy Hebrew landing, one loud CTA, grocery visuals. Super MCP truth: asks before uncertain swaps.

### Aesthetic Direction
- Hebrew RTL; Wolt cyan palette (darker CTA for AA contrast)
- Story first, technical proof second; the real ₪267 Carrefour example is the page's peak (full-bleed deep-cyan band)
- Real generated photography (Gemini image model, no readable logos) + un-retouched chat screenshots; never fake UI mockups
- Fonts: Secular One display, Heebo body, Geist Mono for numbers/code; radius scale 20/28/pill
- Max ~2 eyebrows per page; no em/en dashes in copy; one color-block section per page

### Design Principles
1. Five-second comprehension: רשימה נכנסת → תוכנית קנייה יוצאת
2. No API field names above the developer disclosure
3. One dominant CTA intent (בקשו גישה) leading to the inline access form (no mailto)
4. Progressive disclosure for MCP/REST tooling; FAQ answers self-serve objections before the form
5. Prefer concrete Hebrew outcomes over infrastructure jargon; show the agent asking, not just claim it
